# CTF Web Challenge Titles and Descriptions

## 1) Hidden Admin Panel

Title:
Hidden Admin Panel

Description:
A public website appears normal, but an admin area exists in a hidden path. Discover the hidden route and access the admin page to capture the flag.

## 2) SQL Injection Login

Title:
SQL Injection Login

Description:
A login form uses weak input handling and is vulnerable to SQL injection style authentication bypass. Use crafted input to get into the admin dashboard.

## 3) XSS Discovery

Title:
XSS Discovery

Description:
A comments page reflects user-controlled input into the browser without safe output encoding. Trigger JavaScript execution and use page context access to retrieve the flag.

## 4) IDOR Notes API

Title:
IDOR Notes API

Description:
A notes API exposes records by numeric object IDs but does not properly enforce ownership checks. Enumerate IDs to access data outside your account and find the flag.
